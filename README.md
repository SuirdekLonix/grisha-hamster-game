# 🐹 Hamster Grisha Game / Игра про хомяка Гришу

[Русский перевод ниже]

A cozy text-based Tamagotchi-style game written in Python. This project is dedicated to my real pet — a 1-year and 9-month-old pearl-colored Djungarian hamster named Grisha.

## ✨ Features
* **Pet Profile:** Displays Grisha's breed, beautiful pearl color, and his venerable age.
* **Tamagotchi Mechanics:** Take care of his satiety, energy, and happiness.
* **Petting:** You can gently pet Grisha behind the ear to make him happy.
* **Pet Shop:** Earn coins by taking care of him and buy treats (mineral stone, berry drops) or a play tube.
* **Hamster's Diary:** Every turn showcases a random cute action or thought of Grisha.
* **Auto-Save:** Your progress and coins are automatically saved to a file.

## 🚀 How to Run (via Termux or PC)
1. Install Python if you haven't already:
   ```bash
   pkg install python
   ```
2. Run the game script:
   ```bash
   python grisha.py
   ```

* **Ласка:** Вы можете аккуратно погладить Гришу за ушком, чтобы поднять ему настроение.
* **Зоомагазин:** Зарабатывайте монеты за заботу и покупайте лакомства (минеральный камень, ягодные дропсы) или трубу для лазания.

* **Автосохранение:** Ваш прогресс и монеты автоматически сохраняются в файл.
